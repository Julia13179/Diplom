# Дипломный проект - Автоматизация тестирования Stellar Burgers

Этот репозиторий содержит три части дипломного проекта по автоматизации тестирования.

## Структура проекта

- **Diplom_1/** - Unit тесты для приложения заказа бургеров
- **Diplom_2/** - API тесты для Stellar Burgers API
- **Diplom_3/** - Веб-тесты для Stellar Burgers веб-приложения

## Описание частей

### Diplom_1: Unit тесты
Тестирование классов приложения заказа бургеров с использованием pytest, моков и параметризации.

### Diplom_2: API тесты
Автоматизированные тесты API эндпоинтов Stellar Burgers с использованием requests и allure-pytest.

### Diplom_3: Веб-тесты
Автоматизированные веб-тесты с использованием Selenium, Page Object Model и кроссбраузерного тестирования.

## Быстрый старт

Каждая часть проекта имеет свой README с инструкциями по установке и запуску тестов.
